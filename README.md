# صدقة جارية - حسام حسن شكري

تطبيق ويب تقدمي (Progressive Web App - PWA) تم بناؤه ليكون صدقة جارية عن روح المتوفى **حسام حسن شكري**.
التطبيق يعمل دون اتصال بالإنترنت (Offline) بشكل كامل بعد أول عملية تحميل، ويحتوي على ثلاثة أقسام:
1. **أدعية للمتوفى**: مع إمكانية النسخ والمشاركة.
2. **القرآن الكريم**: النص كاملاً للقراءة دون اتصال (تم تخزين نص القرآن محلياً).
3. **المسبحة الإلكترونية**: عداد تسبيح يحفظ التقدم تلقائياً.

## المميزات الفنية
- **يعمل 100% Offline**: بفضل تقنية الـ Service Worker (بإستراتيجية Cache-First).
- **لا يعتمد على أي شبكات توصيل (CDN) خارجية**: جميع الخطوط، الأيقونات، وملف المصحف تم تخزينها داخل مجلدات المشروع لضمان العمل التام بدون إنترنت.
- **تطبيق PWA قابل للتثبيت**: يمكن للمستخدم تثبيت التطبيق على الشاشة الرئيسية للهاتف (Add to Home Screen).
- **تصميم إسلامي هادئ**: لا يستخدم إطارات عمل ثقيلة وتم الاعتماد على Vanilla HTML/CSS/JS لضمان أقصى سرعة.

## خطوات النشر (Deployment) على GitHub و Vercel

### 1. رفع المشروع على GitHub
1. قم بإنشاء حساب على [GitHub](https://github.com/) (إذا لم يكن لديك حساب).
2. قم بإنشاء مستودع جديد (New Repository) وقم بتسميته `sadaqa-jariya`.
3. قم برفع جميع ملفات هذا المشروع (بما فيها المجلدات `assets`, `css`, `data`, `js`) إلى المستودع الخاص بك إما عبر واجهة الموقع أو باستخدام `git`:

```bash
git init
git add .
git commit -m "Initial commit for Sadaqa Jariya app"
git branch -M main
git remote add origin https://github.com/USERNAME/sadaqa-jariya.git
git push -u origin main
```

### 2. الربط مع Vercel
1. اذهب إلى [Vercel](https://vercel.com/) وقم بتسجيل الدخول باستخدام حساب GitHub الخاص بك.
2. في لوحة التحكم، اضغط على زر **"Add New..."** ثم اختر **"Project"**.
3. ستظهر لك قائمة بمستودعاتك على GitHub، ابحث عن المستودع `sadaqa-jariya` واضغط على **"Import"**.
4. في صفحة إعدادات المشروع التي ستظهر، اترك كل شيء كما هو (لأنه مشروع HTML ثابت، لن تحتاج لتحديد إطار عمل).
5. اضغط على **"Deploy"**.
6. في غضون ثوانٍ، سيتم نشر الموقع وستعطيك Vercel رابطاً مجانياً (مثل `sadaqa-jariya.vercel.app`).
7. افتح الرابط من هاتفك، سيطلب منك المتصفح تثبيت التطبيق. بمجرد تحميله بالكامل، يمكنك إطفاء الإنترنت وستجد أن التطبيق يعمل بشكل ممتاز.

نسأل الله أن يتقبله بقبول حسن وأن يجعله في ميزان حسناته.
